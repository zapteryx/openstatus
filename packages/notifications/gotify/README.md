# @openstatus/notification-gotify

Gotify notification provider for OpenStatus.

## Installation

```bash
bun install
```

## Usage

This package provides notification functions for sending alerts via Gotify:

- `sendAlert()` - Send alert when monitor goes down
- `sendRecovery()` - Send notification when monitor recovers
- `sendDegraded()` - Send notification when monitor is degraded
- `sendTest()` - Send test notification

This project was created using `bun init` in bun v1.0.0. [Bun](https://bun.sh) is a fast all-in-one JavaScript runtime.
